# AWS SAA-C03 Exam Prep

A collection of practice questions, solutions, and video resources for the AWS Certified Solutions Architect – Associate (SAA-C03) exam.

## 📄 Contents

### `AWS_SAA-C03_Questions.md`
Full question bank — **684 questions** with multiple-choice options (A–F), no answer key. Each question is a `## Question N` section with options as a clean bulleted list.

### `AWS_SAA_C03_Answers.md`
Answers and explanations — **560 questions**, each with:
- The question stem
- **Answer:** the correct choice(s)
- **Explanation:** reasoning, keywords, and why distractor options are wrong

> Note: question numbering in the source material has gaps (e.g. it jumps from ~51 to 186 and tops out at 684) and a few entries have little to no content — that reflects the original source, not a conversion error.

### Video Resources (YouTube)
- **Playlist:** [Amazon Solution Architect Certificate Prep SAA-C03](https://www.youtube.com/playlist?list=PL2SluYPF9ZQVrOupgNv8jIB-ZblznwxHX) — 26 videos by *IT India*, covering additional practice questions.

## 📚 About

This repo is a personal study collection for the AWS SAA-C03 certification exam, combining:
- A structured question bank (Markdown, derived from the PDF)
- A structured answer key with explanations (Markdown, derived from raw notes)
- A video playlist for additional practice and walkthroughs

1. Attempt questions in `AWS_SAA-C03_Questions.md`.
